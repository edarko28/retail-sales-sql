# SQL Retail Sales Analysis

## Overview
This project uses PostgreSQL to analyze sales data of a business and answer questions pertaining to sales performance, products and profitability.

## Objectives
-Explore retail sales data using SQL.
- Identify most purchased product.
- Look at sales and profit figures.
- Practice data filtering, sorting and summarisation.
- Generate insights to support business decisions.

## Tools Used
- PostgreSQL 17 (using pgAdmin 4)
- SQL
